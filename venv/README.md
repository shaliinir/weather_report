# 🌦️ Weather Report

A simple Python project that displays the current weather information of a city using a weather API.

## Features
- Get current temperature.
- Check weather conditions.
- View humidity and wind speed.

## Technologies Used
- Python
- Requests
- Weather API

## Installation

1. Clone the repository.
2. Install the required package:

```bash
pip install requests
```

## Run the Project

```bash
python main.py
```
